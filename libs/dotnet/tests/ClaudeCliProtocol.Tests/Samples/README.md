# Samples

Linhas de verdade do `claude -p`, uma por arquivo, copiadas das gravações de `fixtures/` em
2026-11-25 (o `claude` de cada uma está na própria gravação). Os testes do parser conferem nelas os
valores exatos: contagens de tokens, modelos, o texto que o modelo escreveu.

Elas ficam aqui, congeladas, porque a regravação semanal muda esses valores a cada vez. Que as
gravações novas ainda tragam linhas desses tipos é conferido à parte, sem fixar valor nenhum
(`StreamJsonParserTests.The_recordings_still_have_a_line_of_each_sample`).
